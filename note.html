QUESTION 1: List 10 web server and discuss how  they are implemented in web technology with the associated software/program

 

ANSWER:

l Apache HTTP server

l Nginx

l Microsoft IIS

l LiteSpeed Web Server

l OpenLiteSpeed

l Node.Js

l Apache Tomcat

l Caddy

l Gunicorn

l XAMPP

 

1. Apache HTTP server: it listens for HTTP request from browsers and serves web pages (HTML, PHP files).

Associated with PHP, MySQL.

 

2. Nginx: is a web server which is event driven and very fast. It works as a web server, reverse proxy, load balancer.

Associated with Node.Js, PHP-FPM, Docker.

 

3. Microsoft IIS (Internet Information Service): it integrates deeply with Windows and runs: ASP. NET applications, .NET API’s  e.t.c.

Associated with ASP.NET, C#, Windows Server.

 

4. LiteSpeed Web Server: A commercial alternative to Apache but much faster. It supports Apache configurations but handles it more efficiently.

Associated with PHP, WordPress.

 

5. OpenLiteSpeed: The open-source version of LiteSpeed. It works with LSAPI instead of PHP-FPM for faster PHP processing.

Associated with PHP, WordPress.

6. Node.is (As a web server):  It can act as a web server using libraries like Express.js.

Associated with JavaScript, Express.js.

 

7. Apache Tomcat: It runs java web applications and also interpretes JSP (Java Server Pages)

Associated with Java, JSP, Servlets

 

8. Caddy: It automatically provides HTTPS using Let’s Encrypt. Very popular for modern secure deployments.

Associated with HTTPS, DevOps, Docker.

 

9. Gunicorn: It is a Python WSGI server. It runs Python web apps and is usually placed behind Nginx.

Associated with Python, Django.

 

10. XAMPP: It is a bundle that serves as a local development server where beginners learn web development locally.

Associated with PHP, MySQL, Apache.
